# site-monitor

Webサイトが外から見られるかを、15分ごとに確かめるだけのリポジトリです。

- 確かめること：ページが表示されるか（200）、エラーの表示が出ていないか、決まった文字が含まれているか、SSL 証明書の期限まで14日以上あるか
- 一瞬の不調では知らせないよう、失敗したら1分おきにあと2回やり直す
- だめだったときは GitHub Actions の「失敗」になり、GitHub からメールが届く
- 確かめるページは `sites.txt`（1行に「URL 含まれるはずの文字」）

手で確かめる：Actions → 「サイトが見られるか確かめる」→ Run workflow
